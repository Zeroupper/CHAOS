# Contributing to CHAOS

Hey there! Thanks for considering contributing to CHAOS — we really appreciate it. Whether it's a bug fix, a new feature, or just improving the docs, every contribution helps.

## Getting started

```bash
git clone git@github.com:Zeroupper/CHAOS.git
cd CHAOS
uv sync
```

That's it — you're ready to go!

## How to contribute

1. **Fork** the repository
2. **Create a branch** from `master` (`git checkout -b my-feature`)
3. **Make your changes** — keep them focused on one thing
4. **Review changes** - Review changes with Claude/Codex (helps a lot if it's over a review)
5. **Commit** with a clear message explaining what and why
6. **Push** to your fork and **open a Pull Request**

## A few guidelines

- One feature or fix per PR keeps things easy to review
- Follow the existing code style
- Update docs if your change affects how things work

## Found a bug?

Please open an [issue](https://github.com/Zeroupper/CHAOS/issues) and include:
- What you expected vs. what happened
- Steps to reproduce
- Your environment (OS, Python version, RAM)

## Not sure where to start?

Check the [open issues](https://github.com/Zeroupper/CHAOS/issues) — anything tagged is fair game. Or just open an issue to ask a question. We're friendly, promise!
